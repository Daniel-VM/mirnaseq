## Pipeline overview

The pipeline is built using [Nextflow](https://www.nextflow.io/) and processes data using the following steps:

* [FastQC](#fastqc) - Raw read QC
* [TRIM_GALORE](#trim_galore) - Adapter and quality trimming
* [MultiQC](#multiqc) - Aggregate report describing results and QC from the whole pipeline
* [miRDeep2](#mirdeeep2) - Known and novel microRNA identification + quantification
* [Pipeline information](#pipeline-information) - Report metrics generated during the workflow execution


### FastQC

<details markdown="1">
<summary>Output files</summary>

* `fastqc/`
    * `*_fastqc.html`: FastQC report containing quality metrics.
    * `*_fastqc.zip`: Zip archive containing the FastQC report, tab-delimited data file and plot images.

</details>

[FastQC](http://www.bioinformatics.babraham.ac.uk/projects/fastqc/) gives general quality metrics about your sequenced reads. It provides information about the quality score distribution across your reads, per base sequence content (%A/T/G/C), adapter contamination and overrepresented sequences. For further reading and documentation see the [FastQC help pages](http://www.bioinformatics.babraham.ac.uk/projects/fastqc/Help/).

### Trim Galore
<details markdown="1">
<summary>Output files</summary>

* `trim_galore/`
    * `*_trimming_report.txt`: Trim Galore report containing process metrics.
    * `*__trimmed.{fq,fq.gz}`: archieves containing the reads that passesd both adapter and QC trimming.
</details>

[Trim Galore!](https://www.bioinformatics.babraham.ac.uk/projects/trim_galore/) is a wrapper script that performs quality and adapter trimming. It also performs quality control on processed reads. See [Trim Galore's User Guide ](https://github.com/FelixKrueger/TrimGalore/blob/master/Docs/Trim_Galore_User_Guide.md)


### MultiQC

<details markdown="1">
<summary>Output files</summary>

* `multiqc/`
    * `multiqc_report.html`: a standalone HTML file that can be viewed in your web browser.
    * `multiqc_data/`: directory containing parsed statistics from the different tools used in the pipeline.
    * `multiqc_plots/`: directory containing static images from the report in various formats.

</details>


### miRDeep2
<details markdown="1">
<summary>Output files</summary>

* `mirdeep/`
    * `mapper/`:   maps processed reads against reference genome.
    * `mirdeep2/`: miRNA detection on deep sequencing data.
    * `quantify_themall/`:  Quantification of known and novel miRNAs. 
</details>

miRDeep2 is a software for known and novel miRNA identification and quantification in deep sequencing data. It provides excelent modules to flexibly analyze and handle microRNA sequencing data.  

See [miRDeep2](https://www.mdc-berlin.de/content/mirdeep2-documentation?mdcbl%5B0%5D=/n-rajewsky%23t-data%2Csoftware%26resources&mdctl=0&mdcou=20738&mdcot=6&mdcbv=71nDTh7VzOJOW6SFGuFySs4mus4wnovu-t2LZzV2dL8).
